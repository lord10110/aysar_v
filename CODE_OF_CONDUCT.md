# Code of conduct

Be kind, be specific, assume good faith.

- Treat everyone with respect. No harassment, discrimination or personal attacks, in any channel.
- Criticise work, not people. Say what is wrong and, if you can, how to fix it.
- Give newcomers room to learn. Point to the docs before pointing out the mistake.
- Maintainers may edit, remove or decline contributions and comments that break these rules, and may remove repeat offenders from the project.

Report problems privately to the maintainers (see SECURITY.md for contact routes).
